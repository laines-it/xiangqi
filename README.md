# Xiangqi

Локальное рабочее пространство разделено на две независимые части:

- [`ml/`](ml/) — локальные Jupyter-ноутбуки и датасет Online Chinese Chess;
- [`site/`](site/) — статический PWA-тренажёр по оценке позиций.

Сайт публикуется из `site/` в GitHub Pages при каждом push в `main`:

<https://laines-it.github.io/xiangqi/>

ML-артефакты не публикуются в открытом репозитории.

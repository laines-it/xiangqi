# Оценка позиции в сянци — этап 1

## Состав

- 30 задач: по 10 из разделов «Ценность фигур», «Скорость развития» и «Расположение фигур»;
- шкала оценки от −4 до +4;
- выбор уверенности;
- немедленная проверка и русское объяснение;
- статистика точности, направления оценки и средней ошибки;
- фильтр ошибок;
- локальное сохранение прогресса.

## Как открыть

Опубликованная версия: <https://laines-it.github.io/xiangqi/>.

Для локальной работы и PWA-режима запустите HTTP-сервер из этой папки:

```powershell
cd site
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

Прогресс хранится в `localStorage` текущего браузера.
